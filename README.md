#ANALYSIS AND VISUALISATION OF HUMAN DEVELOPMENT INDEX 
ABSTRACT
The Human Development Index (HDI) Analysis Project presents a comprehensive examination of global human development trends using data obtained from the United Nations Development Programme (UNDP). The dataset incorporates HDI values along with its core components—life expectancy, educational attainment, and Gross National Income (GNI) per capita—enabling a multidimensional assessment of development across countries and regions. The primary objective of this project is to design and implement an interactive data visualization dashboard that provides users with an intuitive platform to explore, compare, and interpret global HDI statistics.

Through the use of advanced visualization tools, the dashboard integrates bar charts for cross-country comparisons, line graphs for analyzing temporal trends, pie charts for examining regional distributions, and scatter plots for investigating correlations between HDI and its sub-indicators. These visualizations enhance user engagement and support dynamic analysis through interactive features such as filters, dropdown selections, and real-time updates.

By transforming complex datasets into clear, accessible visuals, the project enables deeper insights into global development disparities, progress trajectories, and key factors influencing human well-being. This analytical framework not only highlights variations in economic and social outcomes but also underscores the interconnectedness of development indicators. Ultimately, the project demonstrates the significance of data visualization in converting raw numerical information into actionable knowledge, supporting evidence-based policymaking and contributing to a broader understanding of sustainable human development.
